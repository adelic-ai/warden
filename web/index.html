Accountable autonomy · oversight & custody

Don't trust the agent's account of itself. Reconcile it against a plane it can't forge.

warden runs an LLM agent in an isolated, egress-controlled container and reconciles what it said it did — its transcript — against unforgeable ground truth: the host syscalls it actually made and the network it actually reached. That reconciliation is the product. Reading the transcript alone is trusting the thing you're supposed to be watching.

The stack · read bottom-up

Four layers. Each only means something over a working one below it.

  1. Incus wizard Isolated, egress-controlled, audited LLM runner. The substrate everything stands on. substrate · step 0
  2. agentwatch Two-plane reconciliation of self-report against ground truth → CONFIRMED / GAP / NONE. detection
  3. canon Verdicts + chain-of-custody + a machine-checkable claim of what's covered and what isn't. attestation · prov
  4. omega + ATLAS Coverage cartography — what we catch, and where we're silent, on the AI-threat spine. coverage

Build and validate bottom-up. The top is named for direction, not built first.

How it holds together

A privileged sliver for ground truth; everything else unprivileged.

01 · privilege split

The monitor never runs as root

Ground truth is root-protected by design — that's what makes it unforgeable. So a tiny, dumb root collector copies audit records out to an operator-readable file; the reconciler — the big, data-holding part — runs unprivileged as the operator.

02 · the waist

One schema, many runtimes

Adapters normalize each LLM's raw logs into one NormalizedEvent stream — version-keyed and drift-gated, so a format change under-reports rather than lies. Written once per LLM, shipped to everyone. The stream is also the public entrypoint others build on.
