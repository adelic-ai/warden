Recall / correlation

The 0 rests entirely on scope + runtime-internal classification. The tool_call↔exec matching path was never exercised — the benign run used list_directory, which runs in-process and never execs. A run_shell_command run is required before recall can be called validated.

Self-report fidelity

Gemini logs tool calls name-only unless logPrompts is on (function_args exists but is gated behind prompt-bearing logging). Reconciliation authorizes on timestamp, so this doesn't break detection — but a command-level "claimed vs actual" check can't be built on the default config.

One benign run, one host. Nothing here is actuarial-grade yet — these are reproductions and single-run measurements, reported as such.
